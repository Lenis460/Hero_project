## 1. 坐标系与符号约定（宪法，摘自 task.md）

- 底盘系 C：原点底盘几何中心，+x 车头，+y 车体左侧，+z 向上；+wz 俯视逆时针。
- 云台系 G：+xG 枪口方向，+yG 枪口左侧；θ = +xG 相对 +x 的逆时针角 [rad]。
- 轮编号：FL=0、FR=1、RL=2、RR=3（车顶俯视、车头朝上）。
- 单位全 SI：m、m/s、rad、rad/s。

## 2. 坐标旋转 v_C = R(θ)·v_G

同一个速度向量，G 系坐标为 (vx_G, vy_G)，求 C 系坐标。G 系是 C 系绕 z 旋转 θ 得到，
向量坐标转换方向与坐标系旋转方向相反：

```
vx_C =  cosθ · vx_G − sinθ · vy_G
vy_C =  sinθ · vx_G + cosθ · vy_G        （标准二维旋转矩阵 R(θ)）
wz    =  wz  （角速度不随平面坐标旋转改变）
```

**验算**（verify_kinematics.py 测试 1）：
- θ=+90°，推杆向前 (1,0) → (0,+1)：云台朝左时"前"就是车的"左" ✓
- θ=180°，推杆向前 → (−1,0)：车后退 ✓

**假设**：云台旋转中心与底盘中心重合（考核说明：英雄机器人满足），因此**无平移项**。
若实际车云台偏心，云台转动时枪口位置会平移，但这不影响"速度指令旋转"的正确性，
只影响弹道解算（视觉组的事）。

## 3. 麦轮逆解算

### 3.1 单轮约束

麦轮沿轮平面（辊子轴向）可以自由滑动、垂直方向正常滚动。轮 i 的安装角 αi（轮轴
与 +x 的夹角）：FL/FR 轮轴朝 ±45°（X 布局）。底盘刚体速度 (vx, vy, wz) 在轮心处产生：

```
v_i = (vx − wz·y_i, vy + wz·x_i)     其中 (x_i, y_i) 为轮心坐标
```

沿"轮子滚动方向"的分量决定轮速：ω_i = (v_i · dir_i) / r，dir_i 为滚动方向单位向量。
X 布局四轮 dir 分别为 (1,−1)/√2、(1,1)/√2、(1,1)/√2、(1,−1)/√2（FL/FR/RL/RR），
轮心 (±a, ±b)。代入展开（√2 与 r 组合吸收）得工程公式：

```
ω_FL = (vx − vy − (a+b)·wz) / r
ω_FR = (vx + vy + (a+b)·wz) / r
ω_RL = (vx + vy − (a+b)·wz) / r
ω_RR = (vx − vy + (a+b)·wz) / r
```

### 3.2 物理自检（verify_kinematics.py 测试 2）

- 纯前进：四轮同正 ✓
- 纯左移 (vy=+1)：左前 −、右前 +、左后 +、右后 − —— 对角同号、左右反号，X 布置横移特征 ✓
- 纯逆时针 (wz=+1)：左侧 −、右侧 +，右侧轮"推"着车逆时针 ✓

### 3.3 假设清单

1. **X 布局**（俯视辊子呈 X）。若是 O 布局，vy 与 wz 的符号项要变——基地确认安装方式。
2. 轮子无打滑、辊子无侧向摩擦（理想麦轮）。实车横移会略漂，属正常。
3. a = 0.275（前后半轴距）、b = 0.225（左右半轮距）、r = 0.07786 ——**初值待实测**；
   考核说明原文"左右轮间距 0.45 m，左右轮间距 0.55 m"疑有笔误，第二处按前后轴距理解。
4. 解算输出为**轮端**角速度；电机轴 = ×14（减速比待确认）。
   PID 的目标与反馈必须同侧同单位（我们统一用轮端 rad/s，电流指令换算在驱动层）。
5. 电机物理正反方向与"虚拟轮端方向"的差异由驱动层 `wheel_sign[4]` 表修正，
   **全局公式符号永不改动**。

## 4. 跟随模式符号推导（chassis.cpp）

θ = γ − ψ（γ 云台世界航向、ψ 底盘世界航向）。底盘以 wz = ψ̇ 旋转：

```
θ̇ = γ̇ − ψ̇ = 0 − wz    （云台不动时）
```

要 θ→0 需 θ̇ 与 θ 反号 → **wz 与 θ 同号**。Pid 输出 = kp·(target − feedback)，
取 feedback = −θ 得 u = +kp·θ，方向正确；微分作用于 −θ 等效对 θ 速率产生阻尼。
（集成测试第 5 项验证：θ=+0.5 → wz=+2.0 > 0 ✓）
