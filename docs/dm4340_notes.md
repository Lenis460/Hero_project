## 1. 已按手册实现（不再是占位）

| 项 | 手册内容（V1.3 p12-16） |
|---|---|
| 总线 | CAN 2.0 标准帧，默认 1 Mbps（波特率寄存器 0x23，>1M 自动变 CAN FD，勿动） |
| 反馈方式 | **问询式**：收到 ID 匹配（低 8 位校验）的帧才回发反馈——一问一答 |
| 位置速度控制帧 | ID = `0x100 + CAN_ID`，D[0..3] p_des float 小端（rad），D[4..7] v_des float 小端（梯形限速，恒正） |
| 使能帧 | ID 同控制帧（`0x100+ID`），数据 `FF FC FF FF FF FF FF FF` |
| 失能帧 | `FF FD FF FF FF FF FF FF`（失能为上电默认状态） |
| 清错帧 | `FF FB FF FF FF FF FF FF`；保存零点 `FF FE ...` |
| 反馈帧布局 | D0 = `ID \| ERR<<4`；D1..2 = POS **大端** int16；VEL 12 位 = D3<<4\|D4>>4；T 12 位 = (D4&0xF)<<8\|D5；D6=T_MOS ℃；D7=T_Rotor(线圈) ℃ |
| 线性映射 | 位置 16 位默认 ±12.5 rad；速度 12 位默认 ±30 rad/s；扭矩 12 位默认 ±10 N·m（调试助手可改，**收发两端必须一致**） |
| ERR 码 | 0 失能（上电默认）1 使能；**3 输出轴校准异常 / 4 传感器异常 / 5 编码器校准异常**；8 超压 9 欠压 A 过流 B MOS过温 C 线圈过温 **D 通讯丢失** E 过载 |
| 位置初值 | 上电后位置输出限定在 [-π, π] rad |
| 模式切换 | 改模式寄存器 0x0A（1=MIT 2=位置速度 3=速度 4=力位混控）；切换清零指令值；**建议先读精确位置(寄存器 0x50)再切、零速切换防冲击** |

## 2. 现场确认清单（M1/M4，确认后调 MarkProtocolConfirmed() 打开发帧许可）

- [ ] 实物铭牌型号/电压版本（是否 DM-J4340-2EC；24V/48V）
- [ ] CAN_ID / Master ID 实际值（调试助手读；Master ID 默认 0，多电机总线必须改）
- [ ] 模式寄存器 0x0A = 2（位置速度模式），并用"存储参数"保存（仅失能态生效）
- [ ] 调试助手参数页的 Pos/Vel/Torque 映射范围设定值（与驱动 Config 一致）
- [ ] CAN 通讯丢失保护：确认 ERR=D 的触发超时配置（第三层保护）
- [ ] pitch 机械限位实测 -> 收紧 Config::pos_min/pos_max 并留余量

## 3. 三层安全（对应 task.md 门槛第 6 条）

1. 软件安全门：SafetyGate + Driver::ReadyForCommand()（协议确认 ∧ 反馈在线 ∧ ERR=1）
2. 上层通信：遥控器/上下板超时 -> 清零 + 失能帧
3. 电机内部：通讯丢失保护（ERR=D，达妙驱动器自带，需配置确认）

## 4. 风险备忘

- **发一帧动一帧**：断发 ≠ 停（保持上一帧）；停 = 发 v_des=0 目标帧或失能帧；调试少打断点
- 反馈 POS 上电限 [-π,π]：pitch 初始标定要以"上电时刻"为基准
- 存储参数写 flash（~30ms，寿命 1 万次）：不要在控制循环里发
- 与 3508/C620 差异：C620 电流帧 0x200 起/rpm 反馈/发 0 即停；达妙语义完全不同，驱动层禁止混用
- yaw 电机型号未知：若非 4340 则单独建驱动，不复用本文件帧格式
